# For Sreelakshmi ♡

A small, static romantic page made with the three photos from `/home/dr3/Documents/us`.

Live site: <https://vox-cyber.github.io/for-sreelakshmi/>

## Run it locally

From this directory, run:

```bash
python3 -m http.server 4173
```

Then open <http://127.0.0.1:4173>.

## Background song

The music button now uses the official YouTube upload of **Pesamale** by Siri Xander
and Arra Aria Khayal:

<https://www.youtube.com/watch?v=ptwUYrguUI8>

The official player is embedded in the page and controlled by the music button.
Browsers generally require the visitor to click the button before audio can play.
The song is streamed from YouTube rather than copied into the project.
